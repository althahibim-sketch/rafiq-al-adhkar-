# رفيق الأذكار (Rafiq Al-Adhkar) 📿

تطبيق إسلامي متكامل واحترافي مبني بأحدث تقنيات **Flutter**، صُمم ليكون رفيقاً يومياً للمسلم في المحافظة على الأذكار النبوية المأثورة، ومواقيت الصلاة، والتسبيح، وسلسلة الالتزام اليومي.

> **«أَحَبُّ الأَعْمَالِ إِلَى اللَّهِ أَدْوَمُهَا وَإِنْ قَلَّ»** — صحيح البخاري ومسلم  
> **برمجة وتطوير:** **م. محمد الذاهبي**

---

## ✨ المميزات الرئيسية

### 1. 📖 أذكار وأدعية مأثورة ومحققة بالسند
- **8 أقسام أذكار شاملة ومشكولة بدقة:**
  - أذكار الصباح وأذكار المساء.
  - أذكار النوم وأذكار الاستيقاظ.
  - أذكار بعد الصلاة المفروضة.
  - الرقية الشرعية من الكتاب والسنة.
  - أدعية تفريج الكرب والهم والحزن.
  - أذكار دخول وخروج المسجد.
- **تخريج وفضل الذكر:** نافذة تفاعلية تشرح فضل كل ذكر وروايته وسنده الصحيح.
- **مشاركة ونسخ الأذكار:** إمكانية نسخ أي ذكر أو مشاركته عبر وسائل التواصل بضغطة واحدة.
- **المفضلة الذكية:** حفظ الأذكار المفضلة لسرعة الوصول إليها في أي وقت.

### 2. 📿 السبحة الإلكترونية التفاعلية
- **8 صيغ تسبيح واستغفار وصلاة على النبي ﷺ.**
- **خيارات الأهداف:** (33، 100، أو عدد مفتوح غير محدود).
- **وضع ملء الشاشة (Full-Screen Mode):** للتسبيح باللمس في أي مكان على الشاشة دون الحاجة للنظر إليها.
- **اهتزاز تفاعلي واقعي (Haptic Feedback):** اهتزاز خفيف مع كل تسبيحة، واهتزاز مميز عند اكتمال الهدف.

### 3. 🕌 مواقيت الصلاة والقبلة
- **حساب فلكي دقيق:** يدعم 19 عاصمة عربية وإسلامية بالدقائق والثواني.
- **العد التنازلي التفاعلي:** بطاقة ذكية على الشاشة الرئيسية توضح الصلاة القادمة والوقت المتبقي لها.
- **بوصلة القبلة الجرافيكية:** تحديد دقيق لاتجاه الكعبة المشرفة بالنسبة للشمال الحقيقي.

### 4. 📅 التقويم الهجري
- حساب هجري فلكي آلي معروض ومحدث تلقائياً أعلى واجهة التطبيق الرئيسية.

### 5. 🔥 سلسلة الالتزام اليومي (Daily Habits & Streaks)
- **عداد الأيام المتتالية (Streak Days):** تحفيز يومي للمحافظة على الأذكار.
- **شريط أيام الأسبوع:** متابعة الأيام المنجزة من السبت إلى الجمعة.
- **إحصائيات إنجاز متكاملة:** إجمالي التكرارات اليومية، إجمالي التسبيحات، وعدد الأذكار المكتملة.

### 6. ✍️ أذكاري الخاصة (Custom Adhkar)
- إمكانية إضافة أذكار وأدعية مخصصة بأهداف محددة وتعديلها وحذفها.

### 7. 🎨 واجهة وتجربة مستخدم عصرية (UX/UI)
- **دعم الوضعين الداكن والفاتح (Dark / Light Mode)** المتناسق مع نظام التشغيل.
- **تكبير وتصغير حجم خط الأذكار** لراحة القراءة لجميع الفئات العمرية.
- **محرك بحث فوري وسريع** في نصوص وعناوين كافة الأذكار.
- **عن التطبيق ومشاركة الأجر:** نافذة توضح المصادر المعتمدة ونية الصدقة الجارية وهوية المطور.

## 🏗️ المعمارية البرمجية (Clean Architecture)

تم بناء التطبيق باتباع معمارية نظيفة وقابلة للتوسع والصيانة:

```text
lib/
├── core/
│   ├── theme/           # السمة العامة، الألوان (الزمردي والذهبي)، والوضع الليلي
│   └── utils/           # حاسبة مواقيت الصلاة، اتجاه القبلة، والتقويم الهجري
├── data/                # نصوص الأذكار المحققة وتصنيفاتها
├── models/              # نماذج البيانات (DhikrItem وغيرها)
├── services/            # إدارة الحالة والتخزين المحلي المستمر (AppStore)
├── widgets/             # المكونات والبطاقات القابلة لإعادة الاستخدام
├── screens/             # الشاشات الرئيسية والتفصيلية للتطبيق
└── main.dart            # نقطة البداية وتشغيل التطبيق
```

## 🚀 تشغيل المشروع محلياً

### المتطلبات:
- تثبيت [Flutter SDK](https://flutter.dev/docs/get-started/install) (الإصدار 3.27 أو أحدث).
- بيئة Android Studio أو VS Code.

### خطوات التشغيل:

1. استنساخ المستودع:
```bash
git clone https://github.com/<username>/rafiq-al-adhkar.git
cd rafiq-al-adhkar
```

2. تثبيت الحزم والمكتبات:
```bash
flutter pub get
```

3. تشغيل الفحص والاختبارات:
```bash
flutter analyze
flutter test
```

4. تشغيل التطبيق على الهاتف أو المحاكي:
```bash
flutter run
```
